# 气候债券指数编制与重述

编制气候债券指数族，管理数据水位、方法版本、调仓和重述。

## 参与方与事实

主要参与方包括指数编制机构、气候数据供应方、债券主数据人员、方法审批人员、机构投资者。领域资料记录以下已经确认的事实：

- 指数引入碳排放强度和气候行动等定量指标
- 核心指数衍生六只子指数
- 截至9月1日相较基准碳排放强度降幅超过19%

## 业务约束

- 债券与发行人主数据
- 气候数据水位
- 指数族依赖
- 权重守恒
- 历史重述

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_006.py` 负责读取和校验这些资料。

