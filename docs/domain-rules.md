# 领域边界

编制气候债券指数族，管理数据水位、方法版本、调仓和重述。

现有领域资料围绕以下边界组织：

- 债券与发行人主数据（评级、停牌、到期等期限事件）
- 气候数据来源、排放口径（S1/S12/S123）与数据密级
- 气候数据水位：计算只可见水位及以前到达的事实
- 合规筛选与指数族依赖（一个核心指数、六只子指数）
- 权重守恒：核心与子指数共享合格性，权重在各自范围内独立精确守恒
- 生效窗口：到期、评级滞后、停牌补救期、数据撤回补救期
- 批次幂等：重送不重复入账，异内容阻断相关发布
- 可恢复调仓任务：故障后按检查点继续，不重复发布
- 历史重述：提议与批准职责分离，原发布冻结，重算视角单独留存

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。
服务实现见 `src/cbi/`，设计见 `docs/service-architecture.md`。
